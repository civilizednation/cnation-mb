개인정보처리방침

c.음악비교분석 (cnation 음악 비교 분석) · https://cnation-mb.vercel.app · 시행일 2026-11-25 (개정 2026-11-25: 드라이브 권한 drive.readonly)

1. 수집하는 정보

이 앱은 서버가 없으며 개인정보를 수집·저장·전송하지 않습니다. 사용자가 불러온 영상·음악 파일, 비교 세션, 별점, 연속 듣기 목록 등 모든 데이터는 사용자의 기기(브라우저 저장소)에만 저장되고 처리됩니다.

2. 구글 드라이브 연동 (선택)

  • 사용자가 원할 때만 구글 계정으로 로그인해 구글 드라이브의 파일을 불러올 수 있습니다.
  • 요청 권한: drive.readonly(읽기 전용) — 앱 안의 드라이브 화면에서 사용자가 폴더를 열거나 검색할 때 폴더·음악/영상 파일 목록(이름·크기·날짜)을 불러와 화면에 보여 주고, 사용자가 직접 고른 파일만 기기로 내려받습니다.
  • 드라이브의 파일을 만들거나 바꾸거나 지우지 않으며, 목록과 파일 내용을 어디에도 저장·전송하지 않습니다 (내려받은 파일은 사용자 기기에만 저장).
  • 로그인한 계정의 이메일 주소는 다음 로그인 때 계정을 자동으로 선택하기 위해 사용자 기기에만 저장되며, 어디에도 전송되지 않습니다.
  • 구글 접근 토큰은 기기에만 저장되며(1시간 후 만료), 앱의 설정 화면에서 언제든 "연결 해제"로 삭제·권한 취소할 수 있습니다.
  • 선택한 파일은 구글 서버에서 사용자 기기로 직접 내려받아지며, 제3자 서버를 거치지 않습니다.
  • 구글 사용자 데이터를 광고, 판매, 제3자 제공, AI 학습 등에 사용하지 않습니다. 구글 API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 준수합니다.

3. 제3자 제공

개인정보를 제3자에게 제공하지 않습니다. 앱은 정적 웹사이트로 Vercel에서 호스팅되며, 호스팅 과정에서 일반적인 접속 기록(IP 등)이 Vercel에 남을 수 있습니다.

4. 데이터 삭제

  • 앱의 설정 → 저장공간에서 세션과 연속 듣기 목록을 삭제할 수 있습니다.
  • 설정 → 구글 드라이브 → 연결 해제로 구글 권한을 취소할 수 있으며, 구글 계정 → 서드 파티 액세스에서도 취소할 수 있습니다.
  • 브라우저(또는 홈 화면 앱)의 사이트 데이터를 지우면 모든 데이터가 삭제됩니다.

5. 문의

개인정보 관련 문의는 앱 관리자(cnation)에게 연락해 주세요.
